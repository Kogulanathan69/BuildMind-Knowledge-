# BuildMind CSV Catalog for Future AI Agents

This folder documents **all discovered local clean-weather and construction-cost CSV files** through schema, counts, checksums, validation states and safe column summaries. It does **not** contain full measurement/rate records.

Begin with `manifest.json`, read each dataset file, then `knowledge/datasets/01_weather/README.md`, `DATA_QUALITY_REPORT.md` and `knowledge/datasets/02_construction_cost/README.md`.

**Critical:** construction cost entries are candidate extractions; do not use them to issue quotations until verified. Public repository does not hold source CSVs. Keep full data in access-controlled storage if redistribution rights permit.
