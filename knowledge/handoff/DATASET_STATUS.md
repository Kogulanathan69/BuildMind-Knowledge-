## Source verification checklist
- [ ] Exact source and downloadable URL
- [ ] Source publisher, publication date, page number
- [ ] Latest amended version; status current / superseded / uncertain
- [ ] Local authority + plot applicability + exceptions
- [ ] Extraction matches source page and units
- [ ] Usage licence or reproduction permission
- [ ] Independent expert check for safety/regulatory conclusions

Do not interpret a planning reference as an enforceable residential building code without evidence.
