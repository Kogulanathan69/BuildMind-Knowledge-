# BuildMind project handoff

Updated 25 October 2026.

The [complete discussion record](docs/discussion-record/README.md) is the main handoff. It covers scope, architecture, data, prototypes, BRD and evaluation. The [topic checklist](docs/discussion-record/TOPIC-COVERAGE.md) is the coverage audit.

## Current state

A working visual browser prototype exists separately from this knowledge repository. It uses plain JavaScript and Three.js; the Angular/FastAPI/PostgreSQL architecture is the proposed implementation direction. The prototype must not be described as a completed automatic constraint-solving or source-backed regulatory system.

The 22-page submission BRD version 1.1 is stored in docs/brd as PDF, Word and Markdown. The separate 26-section uploaded draft was reviewed, not accepted wholesale as an MVP or silently rewritten.

## Continuity rule

Update current status and backlog after work; record decisions with reasons; retain previous records; commit and push. Distinguish proposed, implemented, tested and domain-reviewed. Never infer dataset completeness from archive counts or source availability.
